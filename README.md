# Neural Network From Scratch

A small neural-network library implemented using Python and NumPy.

## Goals

Implement:

- Dense layers
- ReLU
- Softmax
- Cross entropy
- Backpropagation
- SGD
- Momentum
- Adam

Then train the network on a spiral classification dataset.

## Rules

- No PyTorch/TensorFlow for model implementation yet
- Understand every gradient used
- Run experiments rather than only getting one successful model
